# 📖 1. Apresentação do Framework

O Django é um framework web de alto nível escrito em Python que incentiva o desenvolvimento rápido e um design limpo e pragmático. Ele já vem com diversas funcionalidades prontas, como autenticação, painel administrativo e ORM.

---

# 🧠 2. Origem e Filosofia

O Django foi criado em 2005 por desenvolvedores do jornal *Lawrence Journal-World*.

Sua filosofia principal é baseada em:

* **DRY (Don't Repeat Yourself)** → evitar repetição de código
* **Batteries Included** → já vem com tudo pronto
* **Segurança por padrão**
* **Escalabilidade**
